# Marathon Tracker

A personal, installable web app for tracking Charlotte Marathon training —
daily runs, lifting sessions, Hooper Index wellness, Whoop recovery, and an
auto-computed weekly summary.

The app itself lives in [`marathon-tracker-app/`](marathon-tracker-app/) —
see [`marathon-tracker-app/README.md`](marathon-tracker-app/README.md) for
what it is, how to run it locally, how to deploy it to GitHub Pages, and how
to (optionally) wire up live Google Sheets sync.

**Live app:** https://twtperformance.github.io/marathon-tracker/
